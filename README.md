# Bright_Coffee-Case_Study

Project Overview

This project seeks toanalyse transactional sales data from Bright Coffee Shop to identify key sales patterns,
and to  provide actionable recommendations to help improve product performance, to increase sales and revenue.

🎯 Project Objectives
The main objectives of this project are to:

Analyze number of units sold by product type.
Identify the highest- and lowest-performing products.
Calculate total revenue generated from transactions.
Analyze the sales performance of various products.
Identify peak sales periods throughout the day.
Create visual dashboards and charts to communicate business insights.
Provide recommendations that can help improve sales performance.

📊 The Dataset used in this project is:
Bright Coffee Shop Sales

The dataset contains daily transactional information from the Bright coffee shop.

The analysis is mainly focusing on information such as:
Product type
Product details
Unit price
Transaction quantity
Transaction time
Total transaction amount

🏗️ Data Flow & Architecture
This project follows a data pipeline from the original source through data processing, analysis and visualisation.

Data Flow
Source Excel Dataset
        ↓
Convert Excel to CSV
        ↓
Load CSV into Databricks
        ↓
Data Cleaning & Transformation
        ↓
SQL Analysis
        ↓
Processed Dataset
        ↓
Excel / Visualization Tool
        ↓
Pivot Tables & Charts
        ↓
Dashboard & Presentation
        ↓
CEO Recommendations

The architecture diagram created in Miro provides a visual representation of this process.
